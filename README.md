# Лабораторна робота №3. Розгалужувані алгоритми

Номер у журналі K = 20. Для N від 1 до 10 номер задачі дорівнює ((N³ + K²) mod 113) + 1. Програма виконує всі задачі послідовно.

| № | Задача | Приклад введення | Очікуваний результат |
|---|---|---|---|
| 63 | Правильний трикутник у колі | 1 1 | Поміститься |
| 70 | Додатна сума пари | 0 1 -2 | Є така пара |
| 89 | Прямокутник у прямокутнику | 2 3 3 2 | Поміститься після повороту |
| 13 | Сума цифр двозначного числа | -99 18 | 18, двозначна, дорівнює a |
| 74 | Розрахунок у книгарні, суми в копійках | 8000 10000 | Здача 20.00 грн |
| 52 | Точка відносно трикутника | 0 0 4 0 0 4 1 1 | Всередині |
| 66 | Проходження цегли гранню паралельно сторонам отвору | 2 3 5 3 2 | Пройде |
| 9 | Густина двох матеріалів | 2 4 3 6 | Обидві густини дорівнюють 2 |
| 113 | Середнє арифметичне середніх за величиною чисел | 1 8 3 9 4 6 | (3 + 6) / 2 = 4.5 |
| 45 | Фільтр клавіш | a!7 | Літера a, цифра 7 |

У задачі №45 введіть символи з нового рядка. У консолі Visual Studio результат з’являється при натисканні клавіші. Enter завершує програму.

## Запуск

У консолі Developer Command Prompt for Visual Studio відкрийте папку роботи та виконайте:

```bat
cl /utf-8 /std:c17 main.c /Fe:lab.exe
lab.exe
```

У Linux:

```sh
gcc -std=c17 main.c -lm -o lab
./lab
```
